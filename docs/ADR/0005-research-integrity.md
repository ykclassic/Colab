# ADR 0005: Research Integrity and Reproducibility

## Status

Accepted

## Decision

Research and quantitative outputs should preserve sufficient metadata to reproduce and audit the result.

Where applicable this includes dataset identity, dataset version, content hash, feature configuration, strategy version, parameters, code revision, environment, random seed and execution assumptions.

## Rationale

A result that cannot be reproduced cannot be reliably governed.

## Consequence

Experiments and research artifacts require more metadata than a conventional notebook. This additional complexity is intentional.
